% ---------------- The prompt template ----------------
{\large \textbf{2. Paste this prompt (then paste the table under it)}}

\vspace{3pt}
\begin{center}
\fbox{\parbox{0.93\textwidth}{\small\ttfamily
You are my lab QC assistant. Here is a small QC table (below). Work in three\\
explicit, labelled steps and show each one:\\[3pt]
1. REASON: state what a QC anomaly would look like and exactly which limit(s)\\
\hspace*{2.2em}you will check (mass error within $\pm$2 ppm; resolution $>$ 30000; TIC 8--12).\\
2. ACT: check each run against those limits and name any out-of-range run(s),\\
\hspace*{2.2em}listing which specific metric is out of range for each.\\
3. CHECK: state what a human must verify before trusting your answer.\\[3pt]
Use only the numbers in the table. Do not invent any value.\\
\lbrack paste the QC table here\rbrack
}}
\end{center}

\vspace{4pt}

% ---------------- Guiding questions ----------------
{\large \textbf{3. Guiding questions}}\quad{\small (fill in, then compare with a neighbour)}

\vspace{3pt}
\textbf{(a)} Which run did your bot flag, and which specific metric(s) violate spec?

\blk{\linewidth}

\vspace{6pt}
\textbf{(b)} Did it show its \textbf{REASON before it ACTED}? Did it invent any number that is
\emph{not} in the table? (This is the hallucination check.)

\blk{\linewidth}

\vspace{6pt}
\textbf{(c)} What did it say a \textbf{human} must verify --- and do you agree? Where should the agent
\emph{stop} and a person sign?

\blk{\linewidth}

\vspace{6pt}\hrule\vspace{4pt}

% ---------------- What a good answer looks like ----------------
{\large \textbf{4. What a good answer looks like}}

\vspace{3pt}
\begin{center}
\fbox{\parbox{0.93\textwidth}{\small
A good answer flags \textbf{QC-04}, and names \emph{why}: mass error $+5.6$ ppm (limit $\pm 2$),
resolution $22{,}300$ (limit $>30{,}000$), and TIC $3.1$ (limit 8--12) --- it breaks all three, so it is
a likely miscalibrated / failed run (recalibrate + re-run). Runs QC-01, 02, 03, 05, 06 pass. Crucially,
it (1) states the limits \textbf{before} it checks the runs (reason before act), (2) cites only values
that appear in the table (no invented numbers), and (3) ends by \textbf{deferring the final pass/fail to
a human}: the agent drafts, a qualified person verifies against the instrument logs and signs before any
result is used. If your bot skipped its reasoning, invented a value, or declared a final pass/fail on its
own, that is exactly the behaviour the lecture's \textbf{guardrails} (human review, restricted tools,
logging) are designed to catch.
}}
\end{center}
