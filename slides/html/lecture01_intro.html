Icebreaker — let them laugh; the room relaxes. The joke is fair: a linear regression IS a fitted statistical model, and calling it "AI" changes nothing about the maths. But don't leave them cynical — there's a real gradient here: as you move statistics → ML → deep learning → the loose umbrella "AI," you tend toward larger models that engineer fewer of their own features and tackle messier data. Use the callout to hand off to the nesting diagram: deep learning is not a rival to ML, it's a subset — that's the single relationship to fix in their heads.
Why neural networks · the big promise

Enough neurons can trace almost any shape

Give a network enough neurons and it can approximate essentially any function — any curve, any decision boundary — as closely as you like.

A function is just a rule from input to output; approximate means "get as close as you want."

More neurons → finer pieces → a closer trace. This is the Universal Approximation idea — the reason networks are so flexible.
The single most important reason to care about neural networks. State it plainly: with enough neurons, a network can get arbitrarily close to any input-output rule — every bump of a spectrum, any boundary between "resistant" and "susceptible." The amber trace is built from many simple bends (each a neuron with its activation from the last section) added together; add more neurons and the pieces get finer and hug the teal target more tightly. Define the two jargon words on the slide. The honest caveat to say aloud but not put on the slide: "can" is not "will" — the theorem promises such a network EXISTS, it does not hand you the weights. Finding them is learning (Lecture 2), and stacking layers deep is what makes that search practical (next section). No proof, no formula — intuition only.

Lecture 1 · part two

The neuron

the whole of deep learning is millions of copies of this one tiny thing
Reassure the room: this is the single most important idea of the hour, and it is nothing but multiply, add, and one bend. Once they own one neuron, a network is just many of them wired together — which is literally the next section.
The neuron · anatomy

A neuron: weighted sum → bias → activation

z = w₁·x₁ + w₂·x₂ + b    then    y = f(z)
Walk left to right. Inputs are numbers (two peak intensities, say). Each input is multiplied by its own weight — the weight is how much this neuron cares about that input; weights are what training will learn (Lecture 2). Add the results, plus a bias — a constant nudge that shifts the whole sum up or down. That gives z. Then the activation f bends z into the output — without that bend, stacking neurons would collapse back to one big weighted sum (a single line); the bend is what lets networks model curves. Keep saying it: multiply, add, bend. Two slides from now we put real numbers through this exact picture.
The neuron · the "bend"

Two activations you'll meet all week

The activation is the bend — the only non-straight step. No bend, and a deep stack collapses into one straight line.
Two workhorses. ReLU — "rectified linear unit," but just say: negatives become zero, positives pass unchanged. It is the default hidden-layer activation because it is trivial to compute and trains well (why, in Lecture 2/4). Sigmoid — the S-curve that squashes any number into 0–1, so we read the output as a probability; it typically sits at the very end of a yes/no classifier. The callout is the conceptual payload: activations are the source of non-linearity — remove them and the whole network, however deep, algebraically flattens to a single linear map. Foreshadow: in the worked example next, ReLU turns one neuron's negative sum into a clean 0.

Flip one weight: if , then and — the neuron goes silent.
Do this out loud, slowly — it is the first hand-computation of the course and Quiz 1 mirrors it exactly. The math is now typeset cleanly: z is the dot product of the weight vector and the input vector, plus the bias. Multiply each input by its weight (2×3=6, −1×2=−2), add the bias (+1), get z=5. Then bend: ReLU leaves 5 alone because it is positive; sigmoid maps 5 to about 0.99, i.e. "yes, very confident." The ✏️ check makes the activation matter viscerally: flip one weight negative and the pre-activation goes to −4, and ReLU clamps it to 0 — the neuron contributes nothing. That on/off behaviour, times millions of neurons, is how networks route information. Have them predict the sign before you reveal it.

Frame before computing. Each ROW of W is one neuron's weight list from the last section — neuron 1 is (1, −1, 0); neuron 2 is (0, 1, −1). The input x is the same three numbers for both neurons (three peak intensities: 2, 1, 3). Stacking two neurons' rows makes a 2×3 matrix; running the layer is W·x + b. The shape rule is the only "gotcha": the matrix's column count (3) must match the number of inputs (3); the row count (2) sets how many outputs come out. Second cell, then the payoff. Row 2 (0,1,−1) dotted with (2,1,3) is 0+1−3 = −2, bias 0. Raw layer output z = [2, −2]. Now apply the activation to the whole layer at once: ReLU([2,−2]) = [2, 0]. Land the big idea in the callout: the layer turned three raw inputs into two new numbers [2,0] — a fresh, learned representation — and those two numbers are simply the inputs to the next layer. Stack that move and you have a deep network. Everyone has now run a full layer's forward pass by hand.
Stacking · input → hidden → output

A two-layer network: one forward pass

layer 1 · two hidden neurons · ReLU silences the negative one
layer 2 · one output neuron (bias +1)
The hidden layer's output [3, 0] becomes the input to the next layer. Stack this same move — multiply, add, bend — and you have depth.
The concrete stepping-stone from one layer into depth. Same arithmetic as the last three slides, now wired into a real two-layer net. Read the diagram left to right: two inputs (1, 2), a hidden layer of two neurons, one output. Layer 1 is a matrix–vector multiply then ReLU: neuron 1 gives 1·1+1·2 = 3 (passes), neuron 2 gives 1·1+(−1)·2 = −1 → ReLU clamps it to 0 — the same "goes silent" behaviour they saw with one neuron. The hidden vector is [3, 0]. Layer 2 reads THAT as its input: 2·3 + (−1)·0 + 1 = 7. Say the punchline in the callout: a layer's output is just the next layer's input, so "deep" is nothing more than repeating this move. Sets up exactly why depth builds a hierarchy — the next slide.

Each layer feeds the next, and sees something more abstract than the one before: edges → parts → whole object. Early layers see fragments; deep layers see meaning. That is why "deep."
No one told it to look at edges first — it learned that edges build into parts, and parts into objects.
Close the loop opened at the very start. This is DEPTH, not parallel filters: read it strictly left to right, each layer taking the previous layer's output and building something more abstract — raw pixels → edges → parts (ears, face, body) → the whole object → the label. The single photo, abstracted further at each step, makes the sequence concrete: early layers see fragments, deep layers see the whole. That progression from parts to wholes is what "deep" buys you, and it is why deep nets shine on rich data like images and spectra. Crucial honesty in the amber callout: this hierarchy is LEARNED, not designed — it echoes the engineered-vs-learned pivot and previews Lecture 5, where we watch a network's first layer literally become edge and peak detectors. Depth is powerful but hungry: more layers means more data and care — the bridge to Lecture 2. Say it: your spectra work the same way — raw intensities → peak-shaped bumps → clusters → a signature → the call.
